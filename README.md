# Retro - AI-Powered Smart Study Companion

An AI-assisted study platform designed to help students organize notes, generate flashcards, manage study time and maintain focus.

## Features

- Smart note-taking with AI-based enhancement and organization
- Context-aware study chatbot (Groq LLM API integration)
- Automated flashcard generation for revision
- Pomodoro timer with ambient music support
- Secure authentication with JWT and email verification

## Tech Stack

- Backend: Node.js, Express.js
- Database: MongoDB
- Frontend: React.js
- AI: Groq API (Llama 3.1)

## Quick Start

```bash
git clone https://github.com/theinnocentboy/Retro-v1.0
cd Retro-v1.0
npm install
npm start
```

Visit http://localhost:3000
